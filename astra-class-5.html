ASTRA CLASS 5 Privacy Policy

Last updated: 24 August 2026

ASTRA CLASS 5 is an educational application designed to support Class 5 students with lessons, explanations, practice activities, question banks and learning tools.

1. Information Used by the App

The app may process learning preferences, lesson progress, practice results, study activity, notes and settings entered or generated while using the application.

2. Student Learning Data

Study progress, practice performance, subject activity and related learning information may be stored locally on the user's device to provide learning continuity and progress tracking.

3. Local and Offline Features

Many ASTRA CLASS 5 learning features are designed to work locally or offline. Information used by offline learning features remains on the device unless the user explicitly exports, shares or backs up information through an available feature.

4. Notes and User-Created Content

Notes, answers and other content created by users may be stored locally. Users are responsible for protecting access to their device and local files.

5. Permissions

The application may request device permissions only where required for enabled features, such as file access, audio, sharing or other interactive learning functions. Permission availability depends on the application version and operating system.

6. External Applications

If a user chooses to export or share learning material through another application, that external service may process the selected information according to its own privacy policy.

7. Children's Privacy

ASTRA CLASS 5 is designed for school-age learners. The application is intended to minimize unnecessary collection of personal information and should be used under appropriate parent, guardian or school supervision where required.

8. Data Security

Reasonable technical safeguards are used to protect locally stored application information. No electronic storage system can be guaranteed to be completely secure.

9. Data Retention and Removal

Locally stored learning information generally remains on the device until deleted through application functionality, cleared by the user or removed when application data is deleted.

10. Educational Disclaimer

ASTRA CLASS 5 is an educational support application. Students, parents and teachers should verify important academic information against their prescribed books, syllabus and school instructions.

11. Changes to this Policy

This Privacy Policy may be updated when application features, data practices or legal requirements change.

12. Contact

For privacy or support questions, please use the developer contact information shown on the app-store listing.
