INVESTIGO Privacy Policy

Last updated: 23 August 2026

This Privacy Policy explains how INVESTIGO handles information when you use the application.

INVESTIGO is an investigation workflow, drafting and document-preparation tool. Users are responsible for verifying case facts, legal references, official formats and final documents before official use.

1. Information Used by the App

Depending on the features used, INVESTIGO may process information entered by the user, including:

  • Officer profile and work-related information
  • Police station and case-related information
  • Case diary entries
  • Witness and other investigation-related information
  • NCR and Unnatural Death related records
  • Information entered into investigation and official-document forms
  • Sketch-map and case workflow information
  • User-created reports and documents
  • Application preferences and configuration

2. Local Data Storage

INVESTIGO is designed primarily around local application storage. Information entered into the application may be stored on the user's device so that investigation workflows and documents can be prepared.

Users should protect their device with appropriate security controls and should not allow unauthorized persons to access investigation-related information stored on the device.

3. Backup and Restore

INVESTIGO may allow users to create backups of application data and restore compatible backups.

Backup files may contain information entered by the user. Users are responsible for storing and sharing backup files securely.

License and trial security information is protected separately and is not intended to be transferred as ordinary application data through backups. Backup restoration may also be restricted according to the application's license and installation-binding rules.

4. Document Generation, Export and Sharing

INVESTIGO can generate or assist in generating documents such as case diaries, reports, forms and other investigation-related material.

When a user exports or shares a document, the selected external application or service may process that file according to its own privacy policy.

INVESTIGO does not control how third-party applications handle files after the user chooses to export or share them.

5. Internet and External Services

Some optional application functions may require internet access or may open external applications or services.

Where an external service is used, information intentionally submitted to that service may be handled according to the privacy terms of that service.

6. Trial and Licensing

INVESTIGO provides a 14-day trial period. After the trial period expires, a valid license may be required to continue using protected application functions.

The application may generate an installation or device code for licensing purposes. This code is used to identify the installation for license activation and verification.

Users may voluntarily send the displayed Device Code to the license support contact to request activation.

8. Permissions

9. Sensitive Investigation Information

Users should treat case information, witness information, investigation records and generated official documents as potentially sensitive.

Users are responsible for complying with applicable departmental rules, laws, confidentiality requirements and information-security procedures when entering, storing, exporting or sharing such information.

10. Data Security

Reasonable technical controls are used within the application to protect application and licensing information. However, no device, storage system or electronic transmission method can be guaranteed to be completely secure.

11. Data Retention and Deletion

Locally stored application information generally remains on the device until it is removed through application functionality, cleared by the user, or removed when application data is deleted.

Uninstalling the application may remove app-private local data. Users should create an appropriate authorized backup before deleting application data where retention is required.

12. Children's Privacy

INVESTIGO is a professional workflow and document-preparation application and is not designed or directed specifically for children.

13. Legal and Professional Responsibility

INVESTIGO provides workflow, drafting and document-preparation assistance. It does not replace professional judgment, official records, statutory requirements, departmental instructions or verification by the responsible officer.

Users must verify all generated documents, legal references, case facts and outputs before official submission or use.

14. Changes to this Privacy Policy

This Privacy Policy may be updated when application functionality, licensing, data handling practices or legal requirements change. The latest published version will apply to the current release.
